The key ideas i have learnt so far:

A numpy array is a data structure in Python library that is designed to work with large collections of numbers quickly and efficiently.
Numpy provides :
- Faster calculations
- Less memory usage
- Mathematical operations
- Statistics
- Scientific computing
- Data analysis support

In a numpy array, there are no commas like in a list. 

Numpy arrays are homogeneous, meaning all elements must have the same data type, but that data doesn't have to be numeric.

In understanding numpy arrays, I learnt its attributes such as:
.shape, .size, .ndim and .dtype.

.shape returns the number of rows and columns while .size returns the number or elements in the array.

.dtype returns the data type of the data in the array.

Ndim returns the dimension of the array.

With indexing, there is both positive and negative indexing. Positive indexing starts with counting from 0 and not 1. While negative indexing starts counting from -1. 

With slicing, there is the start : stop : step.
